# GAS ファイル共有アプリ セットアップ手順

## ファイル構成
- `Code.gs` — サーバーサイドロジック(アップロード/ダウンロード/自動削除)
- `Index.html` — アップロード画面(Cloudflare Turnstile組み込み済み)
- `Download.html` — ダウンロード画面(有効/期限切れ/無効の3パターン表示)

## 1. Apps Script プロジェクトの作成
1. [script.google.com](https://script.google.com) にアクセスし「新しいプロジェクト」を作成
2. デフォルトの `コード.gs`(または`Code.gs`)の中身を本リポジトリの `Code.gs` の内容で置き換える
3. ファイル追加(＋ボタン → HTML)で `Index` という名前のHTMLファイルを作成し、`Index.html` の内容を貼り付け
4. 同様に `Download` という名前のHTMLファイルを作成し、`Download.html` の内容を貼り付け

## 2. Cloudflare Turnstile の設定(必須・匿名アップロード対策)
このアプリは「リンクを知っていれば誰でもダウンロード可」ですが、**アップロードは匿名の第三者が無制限に行えないよう Cloudflare Turnstile による検証を必須化**しています。未設定のままデプロイすると、アップロード画面に警告が表示され、アップロード自体ができません(フェイルクローズ)。

1. [Cloudflare ダッシュボード](https://dash.cloudflare.com/?to=/:account/turnstile) にアクセスし(無料アカウントで可)、「Turnstile」→「サイトを追加」
2. ウィジェットモードは「Managed」を推奨。ドメインはデプロイ後の `script.google.com` のURLを想定していますが、Apps Script の Web アプリURLはCloudflare側のドメイン検証に引っかかる場合があるため、ドメイン欄は空欄または `script.google.com` を登録してください
3. 発行された **サイトキー** と **シークレットキー** を控える
4. Apps Script エディタで 左メニュー「プロジェクトの設定」(歯車アイコン)→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」で以下を登録
   | プロパティ名 | 値 |
   |---|---|
   | `TURNSTILE_SITE_KEY` | 控えたサイトキー(公開されて問題ない値) |
   | `TURNSTILE_SECRET_KEY` | 控えたシークレットキー(**絶対に他人に見せない・コードに直書きしない**) |

これにより、`uploadFile()` はサーバー側で Cloudflare の `siteverify` API を呼び出し、検証が通ったリクエストのみを受け付けます。トークンは1回使い切りのため、アップロード成功・失敗に関わらずクライアント側でウィジェットを自動リセットし、次回アップロード時は再検証が必要です。

## 3. Drive詳細サービスの有効化(推奨・完全削除のため)
期限切れファイルは既定では **完全削除**(ゴミ箱を経由しない)を試みます。これには Drive API の詳細サービスが必要です。有効化しない場合は自動的にゴミ箱移動にフォールバックします。

1. Apps Script エディタ左メニュー「サービス」の ＋ ボタン
2. 「Drive API」を選択し「追加」
3. 追加後、`appsscript.json` に `Drive` サービスが登録されていることを確認

## 4. 初回セットアップ(トリガー登録)
1. Apps Scriptエディタの関数選択プルダウンで `setupTrigger_` を選択して実行
   - 末尾の `_` は「クライアント(ブラウザ)から `google.script.run` 経由では呼び出せない」ことを示す
     Apps Script の命名規則です。省略せずそのまま入力・選択してください
2. 初回実行時は権限承認のダイアログが出るので許可する
   - これにより「15分ごとに `deleteExpiredFiles_` を実行する」トリガーが登録されます
   - Googleドライブ保存用フォルダ(`FileShareApp_Storage`)と管理用スプレッドシート(`FileShareApp_DB`)は、初回アップロード時に自動作成されます(`PropertiesService` にIDが保存され、以後再利用されます)

## 5. Webアプリとしてデプロイ
1. 右上「デプロイ」→「新しいデプロイ」
2. 種類の選択で「ウェブアプリ」を選択
3. 設定
   - 実行するユーザー: `自分`
   - アクセスできるユーザー: `全員`(仕様書通り「リンクを知っていれば誰でもアクセス可」とするため。アップロード自体はTurnstileで保護されているため、この設定のままで問題ありません)
4. 「デプロイ」をクリックし、発行された **ウェブアプリのURL** を控える
   - このURLがアップロード画面のURLになります(`https://script.google.com/macros/s/xxxx/exec`)

## 6. 動作確認
1. 発行されたURLにアクセス → アップロード画面が表示される
2. Turnstileウィジェットのチェックが完了する(自動または要クリック)とアップロードボタンが有効化される
3. ファイルを選択し、有効期限を選んで「アップロード」
4. 発行された共有URL(`...exec?token=xxxx`)にアクセスし、ダウンロードできることを確認
5. 有効期限を1時間などに設定して動作確認する場合、`deleteExpiredFiles_` を手動実行することで即時の削除動作も確認可能

## 7. アップロードできるファイル形式について
拡張子・MIMEタイプによるアップロード制限は行っておらず、原則すべての形式をアップロードできます。その代わり、ダウンロード時(`serveFile_`)に **必ず `application/octet-stream` として配信** することで、HTML/SVG/JS等のアクティブコンテンツがブラウザ上で直接実行・レンダリングされることを防いでいます(常に「ダウンロード」として保存され、開くかどうかは受け取った本人の判断に委ねられます)。
ファイル名(拡張子含む)自体は保持されるため、受信者は保存後に自分の判断でファイルを開くことができます。実行ファイル等をダウンロード・実行するかどうかは最終的に受信者側のリテラシーに依存する点にご留意ください。

## 8. トラブルシューティング: `Uncaught SyntaxError: Unexpected token '<'`
`<script>`タグ内にGASのテンプレート変数(`<?= maxSizeMB ?>`など)を直接埋め込むと、評価タイミングや構成によって値が正しく展開されず、ブラウザ側のJavaScriptとして構文エラーになることがあります。
本バージョンでは対策として、`<script>`内ではテンプレート変数を一切使わず、`data-max-size-mb`属性など**HTML要素の`data-*`属性経由で値を受け渡す**方式に変更済みです。Turnstileのサイトキーも同様に `data-sitekey` 属性経由で渡しています。同様のエラーが再発する場合は、`<script>`内に`<?= ... ?>`が残っていないか確認してください。

## 9. 運用上の注意
- コードを更新した場合、既存のデプロイには反映されません。「デプロイを管理」→ 該当デプロイの編集 →「新バージョン」を選択して再デプロイしてください
- `deleteExpiredFiles_` は Drive詳細サービスが有効な場合は完全削除、無効な場合はゴミ箱への移動にフォールバックします(詳細は上記「3. Drive詳細サービスの有効化」を参照)
- 管理用スプレッドシート・保存用フォルダの名前は `Code.gs` 冒頭の `FOLDER_NAME` / `SHEET_NAME` で変更可能です
- ファイルサイズ上限は `MAX_FILE_SIZE`(デフォルト20MB)、有効期限の選択肢は `VALID_EXPIRY_HOURS` で変更可能です
- `TURNSTILE_SECRET_KEY` は Script Properties にのみ保存し、コードやスプレッドシートに直書きしないでください
- ファイル名・MIMEタイプは管理用スプレッドシートへの書き込み時に数式インジェクション対策(先頭が `=` `+` `-` `@` の場合にアポストロフィを付与)を自動的に行っています。`FileShareApp_DB` シートを直接開いても、この対策により危険な数式が実行されることはありません

## 10. セキュリティ上の注意: 関数命名規則を崩さないこと
このWebアプリは「実行するユーザー: 自分 / アクセスできるユーザー: 全員」でデプロイされるため、
**末尾にアンダースコア `_` が付いていないトップレベル関数は、匿名の第三者からオーナー権限で
呼び出せてしまいます**(`google.script.run` はクライアント側のブラウザから直接叩けるため)。

- クライアント(`Index.html`)から意図的に呼び出す `uploadFile` を除き、`Code.gs` 内の関数は
  すべて末尾に `_` を付けています(`deleteExpiredFiles_` / `setupTrigger_` / `removeFilePermanently_` 等)
- 今後 `Code.gs` に新しい関数を追加する場合、**クライアントに公開する意図が明確でない限り、
  必ず関数名の末尾に `_` を付けてください**。付け忘れると、その関数がオーナー権限で外部から
  任意実行可能になり、Driveファイルの削除など重大な影響を及ぼす可能性があります
